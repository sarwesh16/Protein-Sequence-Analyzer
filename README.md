
# 🧬 Protein Sequence Analyzer

A Python-based bioinformatics application developed using Biopython and Streamlit to analyze protein sequences.

## 🚀 Features

- Protein sequence input
- Protein sequence validation
- Calculate protein sequence length
- Amino acid composition analysis
- Calculate amino acid percentage
- Interactive web interface using Streamlit

## 🛠️ Technologies Used

- Python
- Biopython
- Streamlit

## 💻 Installation and Usage

### 1. Clone the repository

```bash
git clone https://github.com/sarwesh16/Protein-Sequence-Analyzer.git
```

### 2. Navigate to the project folder

```bash
cd Protein-Sequence-Analyzer
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
streamlit run app.py
```

## 🎯 Project Objective

To develop a beginner-friendly bioinformatics tool that performs basic protein sequence analysis using Python.
